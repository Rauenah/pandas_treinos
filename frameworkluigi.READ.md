Para que serve

Esse código é apenas um exemplo didático para mostrar como funciona a estrutura básica do Luigi:

• 	Definir tarefas → você descreve o que precisa ser feito (ex.: gerar um arquivo, processar dados).

• 	Definir saídas () → Luigi sabe qual é o resultado esperado (ex.: um arquivo).

• 	Executar () → Luigi realiza a ação necessária para produzir esse resultado.

No caso do exemplo, a ação é só escrever uma frase em um arquivo.
Mas em projetos reais, você pode usar Luigi para:

• 	Baixar dados de uma API.
• 	Processar arquivos grandes (CSV, JSON, etc.).
• 	Treinar modelos de machine learning.
• 	Criar pipelines complexos com várias etapas encadeadas.
